# 故障排查

## 下载末尾报网络错误

**症状**：Chrome/Edge 下载到 99% 时提示"网络错误"。

**排查**：
1. 确认使用最新版本（旧版本可能存在缓冲区数据丢失问题）
2. 检查 Nginx 是否关闭了压缩和缓冲（`gzip off; proxy_buffering off;`）
3. 调大 `BUFFER_SIZE`（默认 8MB，可尝试 16MB 或 32MB）

## Nginx 反向代理后无进度条

**症状**：浏览器下载不显示进度条，断点续传失败。

**排查**：在 Nginx location 块中确保：
```nginx
gzip off;
brotli off;
zstd off;
proxy_buffering off;
```

## 内存持续增长

**症状**：长期运行后内存占用持续上升。

**排查**：检查 `IP_REQUEST_LIMIT` 设置。如果设为 0，IP 限流未启用，可能是其他原因。检查服务器日志是否有异常。

## 下载速度忽快忽慢

**症状**：下载速度在 0 和配置值之间剧烈波动。

**排查**：`BUFFER_SIZE` 过小导致高频暂停/恢复。调大 `BUFFER_SIZE`（8MB → 16MB → 32MB）。

## 私有仓库 API 请求返回 403

**症状**：前端设了 token 但搜索私有仓库仍然 403。

**排查**：
1. 检查 token 是否已过期（查看 `X-Token-Status` 响应头）
2. 确认 token 包含 `repo` 权限
3. 确认仓库名称拼写正确

## 服务启动失败

**症状**：启动时报端口被占用。

**排查**：
1. 修改 `SERVER_PORT` 环境变量
2. 检查是否有其他程序占用该端口
3. 确认没有同时运行多个实例

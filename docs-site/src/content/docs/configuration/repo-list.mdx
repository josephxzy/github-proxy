---
title: 仓库黑白名单
---

控制哪些仓库可以通过代理访问。

| 格式 | 含义 | 示例 |
|------|------|------|
| `user/repo` | 精确匹配 | `user/repo` |
| `user` | 匹配用户所有仓库 | `user` |
| `user/*` | 通配符匹配 | `user/*` |
| `prefix*` | 前缀匹配 | `user/proj-*` |

```toml
[access]
whiteList = ["trusted-user"]
blackList = ["blocked/repo"]
```

或环境变量：`REPO_WHITELIST`、`REPO_BLACKLIST`（逗号分隔）。白名单优先级高于黑名单。

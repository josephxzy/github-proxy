---
title: URL 格式
---

代理接受两种等价的 URL 格式：

| 格式 | 示例 |
|------|------|
| 完整 URL | `https://hub.example.com/https://github.com/user/repo/releases/download/v1.0/file.zip` |
| 短路径 | `https://hub.example.com/user/repo/releases/download/v1.0/file.zip` |

:::caution[短路径限制]
短路径仅适用于 `github.com` 域名下的资源。`raw.githubusercontent.com` 等子域名**必须**使用完整 URL。
:::

## 支持的资源类型

| 类型 | 示例 | 短路径 |
|------|------|--------|
| Release | `user/repo/releases/download/v1.0/file.zip` | ✅ |
| Archive | `user/repo/archive/refs/heads/main.zip` | ✅ |
| Blob | `user/repo/blob/main/file.txt`（自动转 Raw） | ✅ |
| Raw 文件 | `https://raw.githubusercontent.com/...` | ❌ |
| Git | `user/repo.git` | ✅ |
